# cheyoon-mcp

**English** | [한국어](README.ko.md)

A collection of MCP (Model Context Protocol) servers I built, to show how I put MCP to use.

All code is public. "Remote/Local" in the table below describes **where a server runs**, not whether its code is public. No secrets are kept in the code.

## Servers

| Server | Used by | Runs | Description |
|---|---|---|---|
| [`blog-public`](servers/blog-public) | Blog readers | Remote (internet) | Read-only server for listing, reading and searching public blog posts. In progress |
| Personal assistant | Me | Local | Planned |
| Blog authoring (`cheyoon-blog`) | Me | Local | Lives in the blog repository: [JCheyoon.github.io/mcp](https://github.com/JCheyoon/JCheyoon.github.io/tree/master/mcp) |
