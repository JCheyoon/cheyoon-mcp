# cheyoon-mcp

[English](README.md) | **한국어**

제가 만든 MCP(Model Context Protocol) 서버를 모아 둔 저장소입니다. MCP를 어떻게 활용하는지 보여 주려고 만들었습니다.

코드는 모두 공개합니다. 아래 표의 "원격/로컬"은 코드 공개 여부가 아니라 **서버가 실행되는 위치**를 뜻합니다. 비밀값은 코드에 넣지 않습니다.

## 서버 목록

| 서버 | 사용자 | 실행 위치 | 설명 |
|---|---|---|---|
| [`blog-public`](servers/blog-public) | 블로그 독자 | 원격(인터넷) | 블로그 공개 글을 목록·본문·검색으로 읽는 읽기 전용 서버. 만드는 중 |
| 개인 도우미 | 작성자 | 로컬 | 예정 |
| 블로그 작성(`cheyoon-blog`) | 작성자 | 로컬 | 블로그 저장소에 있습니다: [JCheyoon.github.io/mcp](https://github.com/JCheyoon/JCheyoon.github.io/tree/master/mcp) |
